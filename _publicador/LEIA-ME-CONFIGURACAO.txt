── O QUE ESTE SISTEMA FAZ ─────────────────────────────

Você escreve o texto em .txt, coloca na pasta certa,
e clica duas vezes em "2-PUBLICAR.bat".

O programa faz o resto:
  • Gera o HTML do texto
  • Acrescenta o título no índice correto
  • Envia tudo para o GitHub Pages automaticamente
  • Move o .txt para uma pasta "publicados"

Em cerca de 1 minuto o texto está no ar.


── ESTRUTURA DE PASTAS ────────────────────────────────

  C:\TEXTOS\SITE\                 ← pasta principal (repositório GitHub)
  │
  ├── index.html
  ├── contos_index.html
  ├── style.css
  ├── (demais arquivos do site)
  │
  └── _publicador\
      ├── 1-INSTALAR-UMA-VEZ.bat
      ├── 2-PUBLICAR.bat
      ├── publicar.js
      ├── LEIA-ME-CONFIGURACAO.txt  ← este arquivo
      └── rascunhos\
          ├── contos\               ← coloque os .txt de contos aqui
          ├── ensaios\              ← coloque os .txt de ensaios aqui
          ├── novelas\              ← coloque os .txt de novelas aqui
          └── notas\                ← coloque os .txt de anotações aqui

Os arquivos do site (.html, .css, .js) ficam na raiz
de C:\TEXTOS\SITE\. O _publicador\ fica dentro dela
também, mas o GitHub ignora pastas que começam com _
na hora de montar o site — os visitantes nunca veem
essa pasta.


── CONFIGURAÇÃO INICIAL (uma vez só) ─────────────────

PASSO 1 — Instale o GitHub Desktop
  Baixe em: https://desktop.github.com
  Instale normalmente. Abra e faça login com sua
  conta GitHub (crie uma em github.com se não tiver).

PASSO 2 — Crie o repositório local
  No GitHub Desktop, escolha:
    "Create a new repository on your local drive"
  Preencha:
    Name:       site
    Local path: C:\TEXTOS
  Clique em Create repository.

  O repositório estará em C:\TEXTOS\SITE\.

PASSO 3 — Coloque os arquivos do site
  Mova o conteúdo da sua pasta atual para
  C:\TEXTOS\SITE\ (os HTMLs ficam soltos na raiz).

PASSO 4 — Coloque os arquivos do _publicador
  Dentro de C:\TEXTOS\SITE\ crie a subpasta
  _publicador\ e coloque dentro:
    1-INSTALAR-UMA-VEZ.bat
    2-PUBLICAR.bat
    publicar.js
    LEIA-ME-CONFIGURACAO.txt

  Crie também as subpastas de rascunhos:
    C:\TEXTOS\SITE\_publicador\rascunhos\contos\
    C:\TEXTOS\SITE\_publicador\rascunhos\ensaios\
    C:\TEXTOS\SITE\_publicador\rascunhos\novelas\
    C:\TEXTOS\SITE\_publicador\rascunhos\notas\

PASSO 5 — Instale Node.js
  Clique duas vezes em "1-INSTALAR-UMA-VEZ.bat".
  Digite seu nome e email do GitHub quando pedido.
  Feche quando terminar.
  Reinicie o computador.

PASSO 6 — Publique no GitHub Pages
  No GitHub Desktop, clique em:
    Publish repository
  Deixe o nome "site" e clique em Publish.

  Depois acesse github.com, entre no repositório,
  vá em Settings → Pages e em "Branch" selecione
  "main". O site estará no ar em 1-2 minutos.

PASSO 7 — Teste
  Coloque um .txt de conto em:
    C:\TEXTOS\SITE\_publicador\rascunhos\contos\
  Clique duas vezes em "2-PUBLICAR.bat".
  Em 1 minuto o texto está no ar.


── FORMATO DO ARQUIVO .TXT ────────────────────────────

  • Primeira linha: o título do texto
  • Linha em branco
  • O restante: o texto

Exemplo:

  ┌─────────────────────────────────┐
  │ O homem sem sombra              │
  │                                 │
  │ Era uma vez um homem que perdeu │
  │ a sombra numa tarde de verão.   │
  │                                 │
  │ Caminhou pela cidade...         │
  └─────────────────────────────────┘

O nome do arquivo .txt não importa — o título vem
da primeira linha do texto.

Markdown básico funciona:
  **negrito**   → negrito
  *itálico*     → itálico


── USO DO DIA A DIA ───────────────────────────────────

1. Termine o texto no seu editor
2. Salve como .txt na pasta da seção correta:
     C:\TEXTOS\SITE\_publicador\rascunhos\contos\
     C:\TEXTOS\SITE\_publicador\rascunhos\ensaios\
     C:\TEXTOS\SITE\_publicador\rascunhos\novelas\
     C:\TEXTOS\SITE\_publicador\rascunhos\notas\
3. Clique duas vezes em "2-PUBLICAR.bat"
4. Pronto

Pode colocar vários .txt de uma vez — todos serão
publicados em uma única rodada.

Após a publicação, o .txt é movido automaticamente
para uma subpasta "publicados\" dentro da pasta
da seção. Você não perde o original.


── PERGUNTAS FREQUENTES ───────────────────────────────

P: Preciso abrir o GitHub Desktop para publicar?
R: Não. O 2-PUBLICAR.bat cuida de tudo sozinho.
   O GitHub Desktop serve só para a configuração
   inicial.

P: Posso publicar textos de seções diferentes ao mesmo tempo?
R: Sim. Coloque os .txt em cada pasta e clique
   publicar uma vez só.

P: O que acontece se clicar publicar sem nenhum .txt novo?
R: O programa avisa que não encontrou nada e fecha.

P: Posso editar um texto já publicado?
R: Sim. Abra o HTML gerado em C:\TEXTOS\SITE\ em
   qualquer editor de texto, faça a correção, salve,
   e use o GitHub Desktop para fazer commit e push.


── ERROS COMUNS ───────────────────────────────────────

"git não é reconhecido"
  → Rode novamente "1-INSTALAR-UMA-VEZ.bat" e
    reinicie o computador antes de tentar publicar.

"sem título (primeira linha vazia)"
  → O arquivo .txt começa com linha em branco.
    Coloque o título logo na primeira linha.

"repositório não configurado"
  → O passo 2 da configuração inicial não foi feito.
    Abra o GitHub Desktop e crie o repositório.
